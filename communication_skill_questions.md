For latency, I introduced caching and optimized retrieval pipelines. Continuous monitoring and feedback loops helped identify and resolve issues proactively.

The system would use a **RAG architecture**, where relevant context is retrieved and passed to the LLM for response generation. Guardrails would be implemented to ensure compliance and prevent incorrect outputs. Monitoring would track performance, and cost optimization would be achieved through efficient token usage and caching strategies.
